# Portfolio Pessoal — Gracielle Costa

Este repositório contém o código-fonte do **meu portfólio pessoal**, desenvolvido com foco em **desenvolvimento front-end**, **design responsivo**, **experiência do usuário** e **boas práticas de organização de código**.

link: https://gracicosta.github.io/portfolio-gracielle-costa/

O projeto tem como objetivo apresentar de forma clara e profissional informações sobre perfil, experiências, habilidades técnicas e projetos, além de servir como base evolutiva para futuras implementações.

## 📌 Sobre o Projeto

O portfolio foi desenvolvido utilizando **tecnologias web fundamentais**, sem o uso de frameworks, priorizando:

- Performance
- Legibilidade de código
- Estrutura semântica
- Facilidade de manutenção
- Acessibilidade e responsividade

O layout foi pensado para funcionar de forma consistente em **desktop, tablet e dispositivos móveis**, oferecendo uma navegação fluida e intuitiva.


## 🎯 Objetivos Técnicos

- Consolidar conhecimentos em **HTML, CSS e JavaScript puro**
- Aplicar conceitos de **responsividade e design adaptativo**
- Implementar **interações dinâmicas** sem dependências externas
- Criar uma base sólida para evolução futura (Full Stack)
- Desenvolver um projeto com padrão próximo ao ambiente profissional

## 🛠️ Tecnologias Utilizadas

### Front-end
- **HTML5**
  - Estrutura semântica
  - Acessibilidade básica
- **CSS3**
  - Variáveis CSS
  - Media Queries
  - Animações e transições
  - Organização modular de estilos
- **JavaScript (Vanilla)**
  - Manipulação do DOM
  - Controle de estado (Dark Mode)
  - Interações de menu e navegação
  - Persistência com `localStorage`

### Outros Recursos
- **Google Fonts** (Roboto)
- Ícones em SVG
- Layout mobile-first adaptado para desktop
